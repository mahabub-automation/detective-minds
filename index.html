Detective Minds Uploader

Private automation tool for the YouTube channel “The Detective Minds”.

What it does

Detective Minds Uploader is a small personal automation script run by the channel owner on their own server. It renders short detective-riddle videos and uploads them to the owner's own YouTube channel using the YouTube Data API. It is not a public service and does not access any other user's account.

Google data it uses

  • YouTube upload access – to publish the channel's own videos, titles, descriptions and thumbnails.
  • YouTube read-only access – to confirm the correct channel is signed in.
