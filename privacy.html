Privacy Policy

Detective Minds Uploader · Last updated: 7 November 2026

Who uses this app

Detective Minds Uploader is a private tool used only by the owner of the YouTube channel “The Detective Minds” to upload that channel's own videos. It is not offered to the public.

What Google user data is accessed

  • YouTube upload scope (youtube.upload): used only to upload videos, titles, descriptions, tags and thumbnails to the owner's own channel.
  • YouTube read-only scope (youtube.readonly): used only to read the signed-in channel's name to confirm uploads go to the correct channel.

How the data is stored

The OAuth access token is stored only on the owner's private server and is used only by this tool. No Google user data is collected from anyone else.

Sharing

No Google user data is sold, shared with third parties, or used for advertising or any purpose other than uploading the owner's own videos.

Revoking access

Access can be removed at any time from myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
